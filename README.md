



### Ex. 1.1.4: Computing √n

Алгоритм вычисления квадратного корня для положительного целого числа `n` с использованием вавилонского метода. Используются базовые арифметические операции, присваивание и сравнение.

```text
Algorithm Sqrt(n)
    x <- n
    y <- 1
    epsilon <- 0.000001

    while x - y > epsilon do
        x <- (x + y) / 2
        y <- n / x

    return x
```

### Ex. 1.1.5: Quadratic Roots

Алгоритм нахождения действительных корней квадратного уравнения

$$
ax^2 + bx + c = 0.
$$

```text
Algorithm QuadraticRoots(a, b, c)
    if a == 0 then
        return -c / b

    D <- b * b - 4 * a * c

    if D < 0 then
        return "Нет действительных корней"

    if D == 0 then
        return -b / (2 * a)

    root1 <- (-b + sqrt(D)) / (2 * a)
    root2 <- (-b - sqrt(D)) / (2 * a)

    return root1, root2
```

### Ex. 1.1.6: Binary Representation

#### a. Description

Для получения двоичного представления положительного десятичного числа необходимо последовательно делить число на 2 и записывать остатки от деления.

Процесс продолжается до тех пор, пока частное не станет равно 0. Полученные остатки считываются в обратном порядке.

#### b. Pseudocode

```text
Algorithm DecToBin(n)
    binary_str <- ""

    while n > 0 do
        remainder <- n mod 2
        binary_str <- ToString(remainder) + binary_str
        n <- n / 2    // Целочисленное деление

    return binary_str
```

Algorithm DispenseCash(amount)

### Ex. 1.1.8: Closest Elements in Array

Алгоритм поиска расстояния между двумя ближайшими элементами массива.

```text
Algorithm ClosestPairDist(A)
    Sort(A)
    min_dist <- infinity

    for i <- 0 to length(A) - 2 do
        if A[i+1] - A[i] < min_dist then
            min_dist <- A[i+1] - A[i]

    return min_dist
```

Сначала массив сортируется за `O(n log n)`, после чего выполняется один проход по массиву за `O(n)`. Таким образом, общая сложность алгоритма составляет `O(n log n)`.

### Ex. 1.1.9: Array Operations

#### 1. Find Max Value

Алгоритм поиска максимального элемента массива.

```text
Algorithm FindMax(A)
    max_val <- A[0]

    for i <- 1 to length(A) - 1 do
        if A[i] > max_val then
            max_val <- A[i]

    return max_val
```

#### 2. Calculate Average

Алгоритм вычисления среднего арифметического элементов массива.

```text
Algorithm CalculateAverage(A)
    if length(A) == 0 then
        return 0

    sum <- 0

    for i <- 0 to length(A) - 1 do
        sum <- sum + A[i]

    return sum / length(A)
```

### Ex. 1.2.4: Euclid's Algorithm for gcd(31415, 14142)

#### a. Пошаговое выполнение

Выполним алгоритм Евклида для нахождения

$$
\gcd(31415, 14142).
$$

1. `31415 mod 14142 = 3131`
2. `14142 mod 3131 = 1618`
3. `3131 mod 1618 = 1513`
4. `1618 mod 1513 = 105`
5. `1513 mod 105 = 43`
6. `105 mod 43 = 19`
7. `43 mod 19 = 5`
8. `19 mod 5 = 4`
9. `5 mod 4 = 1`
10. `4 mod 1 = 0`

Следовательно,

$$
\boxed{\gcd(31415,14142)=1}
$$

#### b. Оценка скорости

Алгоритм Евклида выполнил **10 делений**.

Алгоритм, основанный на проверке последовательных целых чисел от

$$
\min(31415,14142)=14142
$$

вниз до НОД, в данном случае выполнил бы **14142 операции**, поскольку НОД равен 1.

Таким образом, алгоритм Евклида выполняет значительно меньше операций. По данному сравнению он примерно в

$$
\frac{14142}{10} \approx 1414
$$

раз быстрее.

### Ex. 1.2.5: Prove gcd(m, n) = gcd(n, m mod n)

Пусть

$$
m = qn + r,
$$

где

$$
r = m \bmod n.
$$

Если число `d` является общим делителем `m` и `n`, то оно делит их линейную комбинацию:

$$
r = m - qn.
$$

Следовательно, `d` также является делителем `r`.

Обратно, если `d` является общим делителем `n` и `r`, то из равенства

$$
m = qn + r
$$

следует, что `d` также делит `m`.

Таким образом, пары `(m, n)` и `(n, r)` имеют одинаковое множество общих делителей. Следовательно, их наибольшие общие делители также совпадают:

$$
\boxed{\gcd(m,n)=\gcd(n,m\bmod n)}.
$$

### Ex. 1.2.6: Euclid's Algorithm Behavior for m < n

Если первое число меньше второго:

$$
m < n,
$$

то на первом шаге алгоритма выполняется

$$
m \bmod n = m.
$$

Поэтому следующий шаг имеет вид

$$
\gcd(n,m).
$$

Таким образом, алгоритм фактически меняет числа местами.

Это может произойти максимум **один раз**, поскольку после первой итерации первое число становится не меньше второго.

### Ex. 1.2.9: Min/Max Divisions for Euclid's Algorithm

Рассмотрим числа

$$
1 \leq m,n \leq 10.
$$

#### a. Минимальное количество делений

Минимальное количество делений — **1**.

Это происходит, когда `m` кратно `n`. Например:

```text
10 mod 5 = 0
```

Следовательно,

$$
\gcd(10,5)=5.
$$

#### b. Максимальное количество делений

Максимальное количество делений — **4**.

Оно достигается на соседних числах Фибоначчи в рассматриваемом диапазоне, например для пары `(8, 5)`:

```text
8 mod 5 = 3
5 mod 3 = 2
3 mod 2 = 1
2 mod 1 = 0
```

Таким образом, выполняется **4 деления**.
